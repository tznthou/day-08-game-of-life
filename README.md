# Conway's Game of Life

[← 回到 Muripo HQ](https://tznthou.github.io/muripo-hq/)

網頁版 Conway 生命遊戲模擬器，使用 d3.js 進行 SVG 渲染與資料驅動更新，搭配 Tailwind CSS 打造現代化介面。

## 功能特色

- **50 × 50 網格**：點擊細胞切換生死狀態
- **模擬控制**：開始、暫停、重置、隨機初始化
- **速度調整**：50ms ~ 1000ms（1~20 代/秒）
- **世代計數**：即時顯示當前世代數
- **預設圖案**：6 種經典圖案一鍵載入
- **即時統計圖表**：顯示活細胞數量變化的折線圖（d3.js 經典應用）
- **細胞年齡視覺化**：根據存活世代數自動變色
  - 新生（1-2 代）：翠綠色
  - 年輕（3-9 代）：青藍色
  - 成熟（10-29 代）：靛藍色
  - 穩定（30+ 代）：紫色
- **d3.js 動畫**：
  - 新生細胞彈跳放大效果
  - 死亡細胞縮小淡出效果
  - 顏色平滑漸變（d3.interpolateRgb）
  - 折線圖平滑過渡
  - hover 放大互動

## 技術棧

- **HTML5** - 頁面結構
- **Tailwind CSS** - UI 樣式（Play CDN）
- **d3.js v7** - SVG 渲染、資料綁定、過渡動畫
- **JavaScript ES6+** - 遊戲邏輯

## 遊戲規則

Conway 生命遊戲遵循以下規則：

1. **存活**：活細胞周圍有 2 或 3 個活鄰居時繼續存活
2. **死亡**：活細胞周圍少於 2 個（孤獨）或多於 3 個（擁擠）活鄰居時死亡
3. **繁殖**：死細胞周圍恰好有 3 個活鄰居時復活

邊界視為死亡（非環面）。

## 使用方式

1. 直接開啟 `index.html` 或使用 Live Server
2. 點擊細胞繪製初始狀態，或選擇預設圖案
3. 點擊「開始」觀看演化
4. 調整速度滑桿改變演化速度
